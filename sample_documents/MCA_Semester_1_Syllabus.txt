2. DETAILED SYLLABUS: MCA102 - ADVANCED DATA STRUCTURES AND ALGORITHMS
================================================================================
Course Objective:
To master fundamental and advanced data structures, analyze algorithmic complexity, 
and implement graph algorithms, dynamic programming, and greedy heuristics.

UNIT 1: Linear Data Structures & Complexity Analysis
- Asymptotic Notations: Big-O, Omega, Theta. Amortized time analysis.
- Advanced Linked Lists: Skip Lists, Unrolled Linked Lists, and XOR Linked Lists.
- Multi-dimensional Arrays, Sparse Matrix representations and operations.
- Stack applications: Expression conversion (Infix, Postfix, Prefix), Monotonic Stacks.
- Deque and Priority Queues: Implementation and use-cases.

UNIT 2: Trees and Balanced Search Trees
- Binary Trees: Representation, Traversals (Pre-order, In-order, Post-order, Level-order).
- Binary Search Trees (BST): Insertion, Deletion, and Search operations.
- Self-Balancing Trees: AVL Trees (Single and Double Rotations), Red-Black Trees (Properties and Insertion).
- Multi-way Search Trees: B-Trees, B+ Trees (Node splitting, merging, indexing mechanisms).
- Heaps: Min-Heap, Max-Heap, Binomial Heaps, and Fibonacci Heaps.

UNIT 3: Graph Algorithms and Network Flow
- Graph Representations: Adjacency Matrix, Adjacency List, Compressed Sparse Row (CSR).
- Graph Traversals: Depth First Search (DFS), Breadth First Search (BFS), and Topological Sort.
- Minimum Spanning Trees: Kruskal's algorithm (Disjoint Set Union) and Prim's algorithm.
- Shortest Path Algorithms: Dijkstra's Single-Source Shortest Path, Bellman-Ford (negative weight detection), Floyd-Warshall (all-pairs).
- Network Flow: Ford-Fulkerson method, Edmonds-Karp algorithm, Max-Flow Min-Cut Theorem.

UNIT 4: Algorithmic Paradigms & Dynamic Programming
- Divide and Conquer: Strassen's Matrix Multiplication, Closest Pair of Points.
- Greedy Approach: Fractional Knapsack, Huffman Coding, Activity Selection.
- Dynamic Programming: Longest Common Subsequence (LCS), 0/1 Knapsack, Matrix Chain Multiplication, Traveling Salesperson Problem (TSP).
- Backtracking: N-Queens problem, Subset Sum problem, Graph Coloring.

UNIT 5: Advanced Topics & Computational Complexity
- String Matching Algorithms: Knuth-Morris-Pratt (KMP), Rabin-Karp, Boyer-Moore, Aho-Corasick.
- Trie and Suffix Trees for pattern matching.
- Complexity Classes: P, NP, NP-Complete, and NP-Hard.
- Reductions: 3-SAT to Clique, Vertex Cover to Set Cover.

3. EXAMINATION SCHEME & EVALUATION
================================================================================
- Continuous Internal Assessment (CIA): 40 Marks
  * Mid-term Test: 20 Marks
  * Assignments / Quizzes: 10 Marks
  * Lab / Practical Assessments: 10 Marks
- End Semester University Examination (ESE): 60 Marks
  * Section A: 10 Objective/Short questions (10 x 2 = 20 Marks)
  * Section B: 5 Analytical / Descriptive questions with internal choice (5 x 8 = 40 Marks)
- Passing Criteria: Minimum 40% in ESE and 50% aggregate (CIA + ESE).
